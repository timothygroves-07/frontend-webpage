# Ferienwohnung am See

Frontend-Projekt aus Modul 293: eine statische Website zur Vermietung einer Ferienwohnung.

## Dateien

- `index.html`: Struktur und Inhalt
- `styles.css`: Gestaltung
- `app.js`: Interaktivität

## Lokal ansehen

Ordner in VS Code öffnen und mit der Extension „Live Server“ starten (Rechtsklick auf `index.html` → „Open with Live Server“).

## Geplant

- Bootstrap 5 und jQuery via CDN
- API-Features: Katzenbild, Bitcoin-Preis, Wetter, Ladestationen, Karte
- Bewerbungsformular mit Anbindung an webhook.site
- Veröffentlichung auf GitHub Pages
